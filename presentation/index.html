03 / 08 — JWT Authentication

JWT Auth Flow

1
Pod starts → JWT auto-mounted
/var/run/secrets/kubernetes.io/serviceaccount/token
2
Sidecar POSTs JWT to Conjur
No API key · no password · pod identity IS the credential
3
Conjur validates against GKE OIDC JWKS
Checks namespace + serviceaccount match policy
4
Conjur returns permitted secrets
Least privilege per host identity
5
Sidecar writes secrets.env → tmpfs volume
Never on disk · destroyed on pod termination
authn-jwt/k8s-cluster GKE OIDC emptyDir: Memory Push-to-File
04 / 08 — Secrets Provider Init Container

How Secrets Reach the App

init: secrets-provider             init: secrets-provider
  JWT → Conjur                       JWT → Conjur
  ns=securetask sa=webapp            ns=conjur sa=conjur-ui
  gets password + root-password      gets password (root denied to host)
  writes secrets.env → tmpfs         writes secrets.env → tmpfs
  exits 0                            exits 0

init: env-setup (busybox)
  splits secrets.env
  → /mysql-secrets/  (tmpfs)
  exits 0

main: Flask                        main: Flask
  reads secrets.env                  reads secrets.env
  builds MySQL pool                  calls Conjur API
